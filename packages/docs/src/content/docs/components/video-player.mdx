Video players present visual media and provide controls for playback.

```demo
<pc-video-player
    src="https://placer-toolkit.vercel.app/videos/elephants-dream.webm"
    poster="https://placer-toolkit.vercel.app/images/poster/elephants-dream.webp"
    data-title="Elephants Dream"
>
    <track
        src="https://placer-toolkit.vercel.app/subtitles/elephants-dream/captions-en.vtt"
        kind="captions"
        srclang="en"
        label="English"
        default
    />
    <track
        src="https://placer-toolkit.vercel.app/subtitles/elephants-dream/captions-de.vtt"
        kind="captions"
        srclang="de"
        label="Deutsch"
    />
</pc-video-player>

<p class="pc-caption-m pc-line-height-normal" style="margin-block-start: var(--pc-spacing-m)">
    <strong>Elephants Dream</strong> by Bassam Kurdali
    and the Blender Foundation. Licensed under
    <a href="https://creativecommons.org/licenses/by/2.5">
        CC BY 2.5</a>; transformed to WebM format
    and captions added by Placer.
</p>
```

## Demos

### Poster

Use the `poster` attribute to add a poster (thumbnail) to the video, which shows before the video is played.

```demo
<pc-video-player
    src="https://placer-toolkit.vercel.app/videos/elephants-dream.webm"
    poster="https://placer-toolkit.vercel.app/images/poster/elephants-dream.webp"
></pc-video-player>

<p class="pc-caption-m pc-line-height-normal" style="margin-block-start: var(--pc-spacing-m)">
    <strong>Elephants Dream</strong> by Bassam Kurdali
    and the Blender Foundation. Licensed under
    <a href="https://creativecommons.org/licenses/by/2.5">
        CC BY 2.5</a>; transformed to WebM format.
</p>
```

### Autoplay

Use the `autoplay` attribute to start the video automatically.

```demo

    src="https://placer-toolkit.vercel.app/videos/elephants-dream.webm"
```

### Subtitles and captions

To add subtitles or captions, put a [`<track>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/track) element inside the default slot to import your WebVTT file.

Captions (which include dialogue alongside sound descriptions and speaker identifiers) should use `kind="captions"`. Standard subtitles (which contain dialogue only) should use `kind="subtitles"`.

```demo
<pc-video-player src="https://placer-toolkit.vercel.app/videos/elephants-dream.webm">
    <track
        src="https://placer-toolkit.vercel.app/subtitles/elephants-dream/captions-en.vtt"
        kind="captions"
        srclang="en"
        label="English (CC)"
        default
    />
    <track
        src="https://placer-toolkit.vercel.app/subtitles/elephants-dream/subtitles-en.vtt"
        kind="subtitles"
        srclang="en"
        label="English"
    />
</pc-video-player>

<p class="pc-caption-m pc-line-height-normal" style="margin-block-start: var(--pc-spacing-m)">
    <strong>Elephants Dream</strong> by Bassam Kurdali
    and the Blender Foundation. Licensed under
    <a href="https://creativecommons.org/licenses/by/2.5">
        CC BY 2.5</a>; transformed to WebM format
    and captions added by Placer.
</p>
```
